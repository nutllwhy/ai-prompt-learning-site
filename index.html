第一章：基础认知

1.1 什么是 GPT Image 2

GPT image 2.0 是由 OpenAI 推出的全新图像生成引擎，官方名字是 ChatGPT Images 2.0，模型代号 GPT-image-2。这个版本比之前的图像模型更先进、更强大。

和过去的图像生成工具不同，它不是简单把文字翻译成图画，而是加入了"思考"能力。这意味着它生成图像之前，会先理解你的提示、规划画面结构，再动手画图。

它最值得关注的能力

  • 真实感很强的人像、商品图、空间图和摄影风格画面
  • 包含大量文字的海报、页面、直播界面、信息图和杂志封面
  • 参考图重绘、局部编辑、截图式生成
  • 多格漫画、角色关系图、品牌提案等结构化图像

1.2 GPT Image 2 核心特性

第二章：使用准备与风险提醒

2.1 权限说明

GPT Image 2 是 ChatGPT Plus/Team/Enterprise 用户专属功能，免费版 ChatGPT 不支持该功能。你需要先开通 ChatGPT Plus 会员（20 美元/月）才能使用全部功能。

2.2 账号注册与开通步骤

  1. 访问官方网站：打开浏览器访问 chat.openai.com
  2. 账号注册：点击「Sign up」，使用 Gmail、Outlook 等主流邮箱注册
  3. 开通 Plus 会员：登录后点击左下角账号名称，选择「Upgrade to Plus」
  4. 权限确认：在模型选择下拉框中能看到「GPT-4o」选项即代表开通成功

风险预警：警惕"图片诈骗"时代

gpt-image-2 真正需要警惕的地方，不是它画得假，而是它画得太真。建议坚持四条底线：

  1. 只认原始链接，不把单张截图当证据
  2. 必须做多源交叉验证
  3. 越是结构完整、文字清晰的"真图"，越要提高警惕
  4. 涉及商务投放时，必须索要源文件或原始素材

第三章：提示词基础技巧

提示词（Prompt）是 AI 生图的核心，本质是给 AI 的"创作说明书"。GPT Image 2 无需复杂的权重咒语，自然语言即可实现精准生成。

3.1 提示词核心原则

  1. 精准具体：越具体的描述，生成的画面越符合预期
  2. 逻辑清晰：按照"主体-场景-风格-参数"的顺序描述
  3. 正向描述：多用正向指令告诉 AI"要什么"，而非"不要什么"
  4. 避免矛盾：不要输入相互冲突的指令
  5. 适度控制：核心元素不超过 5 个，风格不超过 2 种

3.2 新手万能公式

【核心主体+细节描述】 + 【场景/环境+背景细节】 + 【艺术风格/表现形式】 + 【构图/镜头/视角】 + 【光影/氛围/情绪】 + 【画面质量/技术参数】

模块拆解

模块 1：核心主体

画面的视觉中心，包括主体的类型、数量、外貌、动作、材质等细节

必填项
模块 2：场景环境

主体所在的环境，包括时间、地点、天气、环境元素

必填项
模块 3：艺术风格

决定画面的整体视觉效果，需明确 1-2 种核心风格

必填项
模块 4：构图镜头

决定画面的视角、主体位置、空间感

可选项
模块 5：光影氛围

决定画面的情绪基调，是画面的"情绪内核"

可选项
模块 6：画面质量

用于提升画面清晰度、质感

可选项

常见错误错误影响解决方案

第四章：提示词进阶技巧

4.1 权重控制

GPT Image 2 不支持（）、[]等权重符号，而是通过自然语言的强调实现元素权重的控制。

权重等级控制方法
最高权重（核心主体）放在提示词最开头；明确说明"画面核心主体、C 位、重点突出"
中等权重（辅助元素）放在提示词中间，明确说明"作为辅助元素、清晰可见"
最低权重（背景元素）放在提示词最后，明确说明"作为背景、弱化处理、虚化"

4.2 主流风格模板

商业人像摄影

佳能 R5 相机，85mm f/1.2 定焦镜头，ISO 100，专业人像打光，皮肤质感细腻

新海诚动画风格

色彩清新柔和，光影细腻通透，氛围感强，细节丰富

中国水墨国风

宣纸质感，笔墨浓淡有致，意境悠远，留白恰当

赛博朋克风格

夜晚雨天，霓虹灯牌，全息投影，冷暖对比色调，蓝紫橙配色

3D 产品渲染

C4D 渲染，OC 渲染器，8K 超高清，3S 材质，质感真实

日系胶片摄影

富士胶片，柯达金 200，胶片颗粒感，暖色调，复古氛围感

4.3 文字生成技巧

  1. 文字要简短，控制在 10 个字以内
  2. 明确说明文字的内容、字体、位置、颜色、大小
  3. 文字所在的区域背景要简洁
  4. 如有错别字，用局部修改功能重新生成

内部练习建议

  1. 每位学习者选择 1 个业务场景，使用"主体-场景-风格-构图-光影-质量"公式写出 3 条提示词
  2. 每条提示词至少迭代 2 轮，记录修改前后的差异和有效指令
  3. 团队复盘时重点观察：文字是否准确、主体是否稳定、品牌调性是否统一、合规风险是否可控
  4. 对外发布前，必须经过品牌、法务或业务负责人确认
